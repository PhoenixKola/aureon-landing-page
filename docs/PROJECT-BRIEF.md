# Project scope

Build a separate, visually ambitious corporate/public landing site for Aureon that communicates connected gym operations without acting as a gym's membership-sales page or login broker. Ground brand and product descriptions in the uploaded snapshot and never modify platform monorepo. Provide gym-specific cinematic entry, product story, EN/SQ/IT, light/dark, legal documents, privacy-light implementation, static hosting artifacts and a runnable local start. No contact form, checkout, pricing guesses, fake app URL, app auth or production DNS changes.

Current implementation supplies full React source, isolated UI/source QA and an intended static export; see `FINAL-PRODUCTION-SIGNOFF.md` for release and cinematic-quality limitations rather than treating a tech build as legal or design approval.
