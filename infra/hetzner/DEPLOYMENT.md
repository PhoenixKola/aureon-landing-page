# Hetzner staging and upload

Use only a **dedicated Aureon subdomain/document root**; don't confuse this marketing site with Aureon's client app, admin, radio, Keycloak, or any sibling website. After legal review, real `SITE_ORIGIN`/`APP_ENTRY_URL` configuration and passing release preflight, run `npm ci && npm run build`. Upload the **contents** of `out/` to the dedicated webroot via SFTP/WinSCP; for Apache include `infra/apache/.htaccess` in that root and confirm the provider permits `Options`, headers and `ErrorDocument`. Get TLS cert via the host's panel. Inspect all deep legal URLs over HTTPS and check actual 404 status. For rollback preserve the prior site-only folder before replacing it. Never recursively delete shared `public_html`. See `docs/DEPLOYMENT-AND-ROLLBACK.md` for the complete checklist.
